# بنية القاعدة (ترييض) — ش٢٥
ملف JSONL؛ كل سطر قاعدة واحدة، مستخرجة من نص مصدر، **كلها في مخزن واحد** مهما كان نوعها.

| الحقل | المعنى |
|---|---|
| id | `<مدرسة>.<كتاب>.<رقم>` |
| kind | usul · qaida_fiqhiyya · dabit · hadith · mantiq · lugha · hukm_furu (حكم فرعي منصوص) |
| school | shafii · hanafi · maliki · hanbali · mushtarak … |
| if | الشروط/الموضوع (قائمة قصيرة بعبارة منضبطة) |
| then | الأثر/الحكم |
| except | الاستثناءات المذكورة في النص |
| disputed | [{school, view}] الخلاف المنصوص فيه على القاعدة |
| basis | الدليل الذي ساقه المصنف (آية/حديث/إجماع/قياس/لغة) |
| scope | الباب (مثال: الأمر، العام والخاص، القياس) |
| src | {book, vol, page, quote} — quote حرفي من النص ≤ ٤٠ كلمة، يُتحقق منه آليًّا |

قاعدة الجودة: لا تدخل قاعدة لا يطابق اقتباسها النصَّ حرفيًّا (بعد التطبيع) في الصفحة المنسوبة أو التي تليها.
المصدر النصي (OpenITI، CC-BY-NC-SA) لا يُرفع إلى المستودع العام؛ المرفوع هنا القواعد باقتباساتها القصيرة فقط.
