# تسليم الجلسة — يُقرأ أول كل جلسة ويُحدَّث آخرها

## الرؤية الثابتة
نموذج صغير مستقل للاستعمال الشخصي، يعمل باستمرار؛ يوجّهه Claude بمهام مكتوبة، ويراجع نتائجه ويختبرها في الجلسة التالية ثم يحمّله المهمة التالية. الجودة قبل الكثرة.

## الآلية
- **الطابور:** ملفات JSON في `tools/builder/tasks/` (id، prompt، tests، expected) في الفرع الرئيسي.
- **العامل:** `tools/builder/worker.py` على Kaggle. يسحب المهام الجديدة كل ١٠ دقائق، يكتب النموذج شيفرة ضاد، ويتحقق منها المحرك الحقيقي (حتى ٣ محاولات).
- **النتائج:** تُدفع إلى الفرع `builder-results` فقط (`results/<id>.json` و`results/done.json`). لا شيء يدخل الفرع الرئيسي إلا بعد مراجعة Claude.
- **المراجعة (دور Claude في أول كل جلسة):** `git fetch origin builder-results` ثم قراءة `results/`؛ المقبول يُنسخ إلى المكتبة مع اختبار، والمرفوض يُسجَّل سببه ويُعاد صياغة مهمته.

## التشغيل (آلي كليًا، دون تدخل من صاحب المشروع)
GitHub Actions (`.github/workflows/builder.yml`) يشغّل نواة على كاجل تلقائيًا: عند دفع مهام جديدة إلى `tools/builder/tasks/` وكل ٦ ساعات. تُجمَع النتائج في `builder-results`. التشغيل اليدوي: `gh api -X POST repos/kaledgmal71-commits/dhad/actions/workflows/builder.yml/dispatches -f ref=main`.
- النموذج الحالي Qwen3-8B بلا وضع التفكير (`enable_thinking=False`)، حتى ٣ محاولات لكل مهمة، وسجل المحاولات محفوظ في `results/<id>.json` (`history`).
- قراءة النتائج: `git fetch -q origin +refs/heads/builder-results:refs/remotes/origin/builder-results`.

## الحالة (٢٠٢٦-١١-٢٢)
- **القياس (٢٠٢٦-١١-٢٢، Qwen3-8B، ٣٠ مهمة بسيطة):** ٢٥/٣٠ = ٨٣٪ مقابل عتبة ٤٠٪ المسجّلة مسبقًا. التسلسل: ١٩ ← ٢٤ (fewshot مولّد من معجم ضاد) ← ٢٥ (اسم الدالة المشكَّل). الفاشل: t02 وt11 وt13 وt27 وt28 (شرائح مخترعة، تعديل قائمة بدل استعمال القيمة المرجعة، منطق أرقام، لصق «و»). العينة صغيرة وبسيطة؛ العتبة التالية على مهام أصعب.
- التشغيل الأول (١٢ مهمة): ٥ نجحت، ٧ فشلت؛ سببان جذريان: (١) ملفات النتائج الحقيقية تُستبدل بملفات المهام عند النسخ، (٢) النموذج يصرف رموزه في «التفكير». أُصلحا في 47ec038 وأُعيد التشغيل على ٣٠ مهمة (t01–t30، كلها محققة بحل مرجعي). تعليمات النموذج تُولَّد الآن بـ `node tools/builder/gen_fewshot.js` من معجم ضاد الفعلي (اختبار تزامن: tests/builder-fewshot.test.js).
- الجامع (٣ غيغابايت داخل متصفح الهاتف) غير قابل للسحب؛ المصدر هو مستودع HusamAlsayedAhmad1/Hadith في Drive (راجع الميثاق لقيود الترخيص).
- Google Drive موصول بـ Claude (بحث/قراءة/رفع). Docs وSheets وSlides غير موصولة.
- نظّفت نواة من ذكر ضاد في الردود العامة (التزام 12f4bef) ولم تُنشر؛ تُنشر بعد قول «انشر».
- مقارنة النماذج (kaggle_gen.sh) تحتاج إعادة تشغيل.

## قياس الدفعة الصعبة (مسجَّل قبل التشغيل، ٢٠٢٦-١١-٢٢)
المهام t31–t50 (أصناف، إغلاقات، خرائط، تعاود، معالجة نص عربي، مصفوفات؛ كلها محققة بحل مرجعي على المحرك الحقيقي).
- العتبة المسبقة: نجاح ≥ ٥٠٪ من أول تشغيل بالنموذج Qwen3-8B والتعليمات الحالية (دون تعديل fewshot بعد رؤية النتيجة قبل تسجيل الرقم).
- الإخفاقات تُسجَّل كما هي مع صنف السبب (دوال مخترعة، منطق، صياغة، بنية)، ثم يُعالَج الجذر لا المهمة.
- إن قلّت النتيجة عن العتبة فهذا سجل سلبي يُدوَّن، ويُبحث تبديل النموذج (ALLaM/Fanar عبر kaggle_gen.sh) بالإجراء نفسه.
