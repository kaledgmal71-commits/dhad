# ميثاق اختيار الخدمات والأدوات السحابية

## المبدأ
لكل وظيفة (كود، حوسبة، استضافة، تخزين، بيانات، نماذج) نختار الخدمة **الأدوم والأجود** معًا، ولا ننتقل عنها إلا لضرورة. الاختيار عند نقطة التقاطع الذهبية: الخدمة التي تستوفي كل الشروط الإلزامية دون التضحية بميزة لازمة.

## الشروط الإلزامية (بالترتيب)
1. **الديمومة:** عمر المزوّد وثبات خطته المجانية عبر الزمن وإمكان الخروج منه بالبيانات كاملة.
2. **الجودة:** ما تبلغه الخدمة في الأداء والموثوقية والحدود قياسًا بحاجتنا الفعلية، مقيسةً لا مفترضة.
3. **التكلفة صفر، شرط قاطع لا استثناء فيه:** لا خدمة تتطلب دفعًا مهما بلغت جودتها. الخطط المدفوعة ليست مرشحة أصلًا إلى أن يتحقق دخل فعلي من المشروع؛ حينها فقط تُعاد المقارنة بالشروط نفسها وتُرقّى الأساسية إلى خطة مدفوعة إن كانت أجود وأدوم.
4. **الاستقلال:** بياناتنا قابلة للنقل، ولا قفل على مزوّد، ولا تعارض مع رخص البيانات (GPL أوراكل فقط؛ ODbL للتدريب فقط ولا تدخل المستودع العام).
5. **الأتمتة:** واجهة برمجية أو CLI يستعملها Claude دون تدخل المستخدم.

## متى ننتقل
فقط عند ضرورة: فقدان الخدمة أو تعطلها أو استنفاد حصتها أو تغيّر شروطها بما يخلّ بشرط إلزامي. الجمال أو الجِدّة ليسا سببًا.

## إجراء الاستبدال (عند الضرورة)
1. نسخة احتياطية كاملة قبل أي تغيير.
2. تقييم البدائل بالشروط نفسها بالترتيب نفسه، وقياس ما أمكن.
3. اختيار نقطة التقاطع الذهبية؛ فإن لم تُوجد خدمة واحدة تستوفي كل شيء فاختيار **أساسية + احتياطية** مجرَّبتين.
4. ترحيل مع اختبار انحدار؛ لا يُعتمد البديل قبل نجاح الاختبارات.
5. تسجيل القرار وسببه في سجل الخدمات أدناه.

## ما لا يُفعل
لا إهدار ميزة قائمة، لا انتقال دون نسخة احتياطية، لا اعتماد خدمة لم تُجرَّب، لا وضع أسرار في المستودع.
