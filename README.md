# dhad-lang
ضاد — لغة برمجة عربية موحّدة مع محرر ودليل شامل


## التشغيل من سطر الأوامر

```
node dhad.js ملف.dhad
node dhad.js -e "اطبع(١ + ٢)"
```

يرجع رمز الخروج ٠ عند النجاح و١ عند الخطأ. دالة `ادخل` تقرأ من الإدخال القياسي.

## المكتبة القياسية

مكتوبة بضاد نفسها (مجلد `stdlib/`) وتُحمَّل بـ `استورد("ضاد/اسم")`:

- `ضاد/نصوص`: قصّ وتقسيم ومحاذاة وتطبيع للعربية (تشكيل، تطويل، ألف، ياء، أرقام).
- `ضاد/أعداد`: تقريب وتنسيق، قواسم وأعداد أولية، متوسط ووسيط، تفقيط حتى ٩٩٬٩٩٩.

بعد تعديل أي ملف في `stdlib/` شغّل `node tools/embed_stdlib.js` ليُدمج في `vm.js`، ثم `node build.js` و`node site/pages.gen.js`.
الاختبارات: `node tests/modules.test.js` و`node tests/stdlib-text.test.js` و`node tests/stdlib-numbers.test.js`.
